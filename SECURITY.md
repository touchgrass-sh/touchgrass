# Security

Please don't open a public issue for security problems. Email **hello@touchgrass.sh** with the details and we'll reply within a few days.

Your bot runs on your own Cloudflare account. If you think your bot token leaked, send `/revoke` to @BotFather, then put the new token in your Worker's settings (BOT_TOKEN) and run the connect step on touchgrass.sh/setup again.
